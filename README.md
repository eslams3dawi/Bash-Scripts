# 🐚 Bash Scripts Practice Repository

## 📌 Overview

This repository contains a collection of **Bash scripting practice projects** created during my journey learning **Linux, automation, and DevOps fundamentals**.
Each script focuses on solving real-world system administration tasks and strengthening shell scripting skills through hands-on practice.

The goal of this repository is to:

* Automate common system tasks
* Improve problem-solving skills in Linux environments
* Build a strong foundation for DevOps tools and workflows

---

## 🛠️ Technologies Used

* Bash Shell
* Linux CLI utilities
* System administration commands

```bash
chmod +x script_name.sh
./script_name.sh
```
